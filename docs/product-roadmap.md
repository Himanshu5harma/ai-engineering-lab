# Prioritized roadmap

## Phase 1 — Coding Arena

Deliver and verify the complete two-challenge loop: validated files → API → Monaco → durable submission → isolated worker → external grading → saved results → evidence-based progress. Keep strict local-only defaults and explicit unavailable states. Verification evidence is recorded separately in `docs/verification.md`.

## Phase 2 — Full practice experience

1. Add ten individually verified challenges: token-window chunking, structure-aware chunking, context budgeting, backoff/jitter, tenant filtering, version-aware evidence, Recall@K/MRR, citation validation, idempotent tools, schema-validated tools.
2. Add explicit solution/explanation reveal, learning/interview modes, attempt notes and failure categories.
3. Store configurable weekly study goal (default 15–20 hours), learning sessions, paths, revision dates and confidence.
4. Implement transparent topic evidence and 1/3/7/14–30 day review intervals; never call one solved exercise mastery.

## Phase 3 — System Design Studio

React Flow canvas, configurable palette, persistent notes/nodes/edges, rubric self-review, and diagram export. Start with an original multi-tenant RAG design, then incident investigation and evaluation platforms. No automated score presented as objective truth.

## Phase 4 — Practical labs

One complete downloadable multi-file FastAPI scaffold first, then RAG and agent workflows with datasets, integration checks and failure scenarios. Use an external local editor before building a cloud IDE. OpsEvidence is a later public/synthetic-data capstone.

## Phase 5 — Optional AI mentor

Provider-neutral hints/reviews with explicit opt-in, credentials kept server-side, usage controls, evidence labels and no automatic code sharing. Deterministic tests remain the correctness authority.

## Phase 6 — Hardening and portfolio

Independent threat-model review, stronger hostile-code isolation, accessibility audit, performance/load characterization, deployment documentation, backup/restore validation, and portfolio exports. Public multi-user execution requires its own security project before exposure.
